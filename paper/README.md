# paper

LaTeX source of *Toy emergent misalignment in small language models pretrained on controlled corpora*;
the built PDF is [`toy_emergent_misalignment.pdf`](toy_emergent_misalignment.pdf). CC BY 4.0
([LICENSE](LICENSE)).

Build from the repository root (see its README): `make pdf` needs a TeX distribution with `latexmk`;
`make figures` also needs lualatex, Ghostscript and the Arial font; `make art` needs headless Google
Chrome; `make arxiv` writes `build/arxiv.zip`, the arXiv upload.

- `main.tex`: preamble, title, abstract, section includes
- `sections/`: one file per section
- `floats/`: one file per figure or table (environment, label, caption)
- `figures/`, `tables/`: generated by `scripts/paper_fig.py` and `scripts/paper_tables.py`;
  each `SOURCE.json` records the commit that drew them
- `art/`: Figures 1, 2 and A5, and Figure 6a (TikZ)
- `refs.bib`: bibliography (natbib, author-year)
